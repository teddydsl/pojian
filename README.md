# 破茧（Pojian）

《破茧》是一款在浏览器中游玩的单人 3D 探索游戏。玩家扮演背着红书包的小刺猬阿吉，走进手工针毡风格的森林，寻找自己的茧房，再通过拜访邻居了解不同的生活视角。

**[在线游玩](https://teddydsl.github.io/pojian/)** · [本地游戏入口](index.html)

## 游戏体验

1. 从林间小路出发，在森林里走走，打开地图找到阿吉的家。
2. 回到自己的茧房，打开人物资料页，观看室内悬挂播放器中的视频，并尝试给茧房上锁、开锁。
3. 返回森林拜访邻居。地图上有三户邻居；当前两户可以进入，铃子家保持上锁。探索任务在拜访两户后完成，进度从 **0/2** 开始。

开场目前以可跳过的进度条呈现。人物资料链接至演示数据页；探索记录和门锁偏好保存在当前浏览器中。

## 操作

| 操作 | 方式 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或方向键 |
| 调整视角 | 拖动鼠标 |
| 与茧房、资料卡和播放器互动 | 靠近后按 `E`，或点击页面底部的互动按钮 |
| 关闭地图、面板或视频 | `Esc` 或对应的关闭按钮 |

页面顶部可打开地图、资料、任务、消息和设置；天气表盘用于查看当前天气。环境声音可在设置中自行开启或关闭。

## 技术与运行

游戏使用 Three.js 渲染 GLB 模型和针毡风格材质，采用本地资源、WebP 图标与 H.264 视频。已构建的 [index.html](index.html) 可直接在浏览器中打开，无需开发服务器。

需要重新构建或运行检查时，使用 Node.js 20.11+、Python 3 和 Pillow：

```bash
npm ci
npm run build:site
npm run test:release
```

`build:site` 生成游戏入口和带内容哈希的资源目录；`test:release` 检查资源、开场、地图、资料与视频、门锁及两户邻居的探索流程。
