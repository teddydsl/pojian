# 阶段 1｜可操作 3D 灰盒

状态：**交互已获用户认可；美术与建模待确认**。可直接打开 `../reviews/stage-1.html` 体验原灰盒。页面所需的 JavaScript 均在本工程中，无远程依赖或本地服务器要求。阶段 2 开始前先验收 [`../reviews/art-style-gate.html`](../reviews/art-style-gate.html)。

## 本阶段目标

验证一条真实可操作的 3D 探索路径：

```text
自己的树洞 → 茧林 → 看到门牌 → 敲门 → 获准进入
→ 另一间树洞 → 从出口返回茧林
```

## 已实现

- Three.js 渲染的三维场景，第三人称镜头，键盘移动与鼠标拖动转向。
- 从自己的树洞出发；森林中央空地与三条通向示例树洞的路径。
- 刺猬占位造型；树形树洞、倒木树洞与树桩树洞三种外形；蘑菇、树木与苔藓色块作为灰盒路标。
- 两间示例树洞预设为开放，敲门后显示同意、门扇收起并进入；一间预设关门，验证不能进入。
- 室内可移动，有资料面板占位；退出后回到森林原树洞附近。
- 页面右侧有动态验收清单，可重置演示。

## 操作

- `WASD` 或方向键：移动。
- 在 3D 画面上按住鼠标并水平拖动：改变镜头方向。
- 靠近树洞或出口按 `E`，也可点击底部出现的交互按钮。

## 已知边界与下一阶段

- 刺猬是**灰盒占位模型**。正式角色将在阶段 2 按用户提供的三视图重新建模，保留刺、脸部比例及整体轮廓。
- 树洞外形和自然褐绿主色取材于新增的树形、倒木与树桩参考；当前是几何体占位，针毡材质和茧丝展开动画属于阶段 2。
- 人物及内容标签尚未提供，因此门牌写“标签待提供”；目前的室内也尚未表达具体内容主题。
- 资料面板只有入口占位。镜头切正面与数据网页接入属于阶段 3。
- 第一版无真实玩家和服务端授权，所有许可均明确为演示预设。

## 阶段 1 验收步骤

1. 打开 HTML，能看到自己的树洞和刺猬，占位模型不妨碍辨认方向。
2. 按 `W` 到房间出口，按 `E` 进入森林；镜头继续跟随。
3. 沿一条路径到开放树洞，看门牌、按 `E` 敲门，看到许可反馈并进入室内。
4. 在室内走动，找到出口，按 `E` 返回森林；位置在刚才的树洞附近。
5. 到苔坡树桩尝试敲门，得到“关门不能进入”的反馈。
6. 点击“重置演示”，回到自己的树洞，清除右侧验收进度。

交互部分已经通过。正式刺猬、针毡森林、蘑菇、茧房外观与室内必须先通过美术基线验收；未获用户确认前不开始阶段 2。
