## 本版交付

| 区域 | 本阶段行为 |
|---|---|
| 顶栏 | 晴、地图、资料、任务、消息、设置六个入口；原有毛毡图标接入，设置使用齿轮图形 |
| 地图 | 左侧地图展示四个家、实际道路、我的位置与朝向；室内标记所在家的世界位置；不传送 |
| 天气 | 晴在表盘 12 点，指针向上；五种天气只读，其余四种暂未开放 |
| 个人数据 | 阿吉、明确标为示例的喜好、已拜访邻居数、徽章空态 |
| 浏览过列表 | 三家的名称、主题、声音与访问状态；只有已拜访家可直接打开对应数据页 |
| 好友 | 真实互访尚未接入，呈现空态 |
| 任务 | 保留探索引导，按家名展示进度；顶栏与设置均可控制追踪条显隐 |
| 消息 | 空态、存档消息呈现、未读数派生和打开即已读；本阶段不生成假消息／奖励 |
| 设置 | 声音、任务、自己的茧房三个开关；演示关门、重置位置、清空记录折叠到“演示工具” |
| 存档 | 迁移旧探索记录与任务显隐；保存新的访问次数、开关门；清空后不重新导入旧记录 |

只读任务追踪条允许边走边看。地图、资料、消息、设置与短暂弹层打开时暂停移动、E 和拖镜头；打开／关闭会清空按键，Esc 逐层关闭并回到对应入口。左侧最多一页，右侧最多一页。左侧页关闭后，按已保存偏好恢复任务追踪条。

个人开关门仅表示本地拜访偏好，不代表真实玩家权限；屋主始终可回家。声音因浏览器手势限制，每次重新打开页面后需点击开启。浏览器若禁止本地存储，设置会提示此次偏好只在当前页面保留。不同浏览器／文件地址是否共享原存档取决于其存储规则；同一 Pages 来源可以读取旧 key。

## 建议验收路线

1. 打开新 HTML，在自己家内走动、拖动镜头；左侧引导不妨碍移动。探索记录应显示三位邻居的家名。
2. 在自己的家和三间邻居家中环顾：墙上的道具文字牌和旧出口牌不再出现，新毛毡洞口是房内出口。靠近后按 E 应可正常返回森林；左侧数据面板仍可打开。随后依次点击顶栏六个入口。天气只能查看，不能切换；个人资料／浏览过／好友从资料下拉进入。检查是否清楚、遮挡是否可接受。
3. 打开地图，再打开设置；左右各保留一页。按 Esc 先关设置，再关地图。打开地图前按住 W，开关面板后松开，角色不应继续滑行；重新按 W 能移动。
4. 设置关闭自己的茧房。出门靠近时显示“阿吉的家 · 今日歇息”，仍然可进入。刷新后开关与任务显隐应保留（浏览器允许存储时）。
5. 在森林沿三条小路拜访邻居。地图的当前标记跟随角色；进入任一家再打开地图，应显示“当前在某某的家（室内）”。三家仍保留各自的布置、光线与声音。
6. 从室内面板打开数据页后切回游戏，直接移动。返回森林后，从“资料 → 浏览过列表”打开指定家的数据页，应仍保留森林中的原位置，不能进入错误房间或残留中间浏览状态。
7. 第一次运行时，未拜访家的按钮应显示“尚未拜访”并禁用；拜访后可用。已有旧版探索记录则应正常继承，不要求重走三家。
8. 消息和好友目前为空态，徽章提示下一阶段开放。查看任务追踪条，确认家名与访问状态一致；此阶段尚无采集物、任务奖励或任务消息生成。
9. 缩窄窗口至约 375px：工具栏独立成行，按钮不出屏；展开面板应可滚动，底部交互提示仍可见。主要游玩操作仍为桌面键鼠，未新增触屏摇杆。
10. 可在设置的演示工具查看帧率、测试铃子的家开关或清空记录。重置位置保留探索记录；清空记录保留界面／个人开关门偏好，刷新不会重新导入旧进度。
