# 阶段 0｜范围与验收基线

状态：**用户已确认通过（附补充要求）**。对应预览页：`../reviews/stage-0.html`。

## 验收后的补充要求

- 刺猬的正式 3D 造型须以用户提供的正面、侧面、背面三视图为建模依据。阶段 1 使用灰盒占位形体，阶段 2 制作与替换正式模型。
- 新增三张参考图：树形森林、倒木与树桩；已放入 `public/assets/references/`。三间示例茧房的外部可从这些木质与苔藓形态取材，颜色以自然的褐、绿、灰和暖光为主，再通过各房间局部色光区分内容。
- 人物标签与内容标签的正式值由用户后续提供。人物标签可能包括年龄、性格、喜好；内容标签可能包括音乐、二次元、体育、休闲、舞蹈等。当前示例主题仅为演示占位，不当作最终标签体系。

## 已确定的产品方向

- 项目：《破茧》，网页端 3D 探索游戏，计划使用 Three.js。
- 玩家：可选基础装扮和自愿公开标签的刺猬；从自己的茧房醒来。
- 世界：偏奇幻的森林，不再是现实城市；房屋采用树洞与编织茧丝的形态，针毡蘑菇、苔藓、树根为主要场景元素。
- 视觉：手工针毡微缩风格。用户提供的五张图片已复制到本工程 `public/assets/references/`，仅供风格参考，不能直接充当 3D 模型。
- 茧房差异：以屋主内容为依据，通过布置、颜色、光和声音表达；不要求所有茧房讨论同一事件。
- 详细信息：室内有信息面板；点击后第三人称镜头切至面板正前方，再打开后续提供的网页数据页面；返回可继续探索。
- 第一版单人体验，茧房主人和进入许可为预设；第二版增加真实玩家互访、开关门、申请、留言和消息。
- 每阶段交付一份可打开的 HTML 验收页；用户确认后才进入下一阶段。

## 第一版的唯一主路径

```text
选择刺猬配色／公开标签 → 自己的树洞醒来 → 走进茧林
→ 查看示例茧房门牌 → 敲门 → 获得预设许可
→ 茧丝展开、进入树洞 → 环绕观察不同布置与声光
→ 靠近资料面板 → 镜头切换 → 打开示例数据网页
→ 返回原房间 → 离开、继续探索
```

第一版的资料页面使用工程内的演示页面，待实际 URL 提供后通过配置替换。演示人物与数据均应标注为示例。

## 建议的最小空间布局

一片小型森林，中央空地连接自己的树洞和三条短路径。每条路径通向一间示例茧房；蘑菇、苔藓和不同树干轮廓提供路标。玩家不需要地图界面也能找到目标。第一版只保证地面路线，不做飞行、复杂跳跃或大型开放世界。

## 三间示例茧房（待用户确认的内容提案）

| 内容主题 | 空间线索 | 色光 | 声音 | 面板入口 |
|---|---|---|---|---|
| 自然观察 | 标本、叶片、微缩观察台 | 苔绿、透进的暖阳 | 风、叶、鸟 | 叶脉面板 |
| 远行见闻 | 路标、地图碎片、旅行物件 | 琥珀、暮蓝 | 风铃、远处脚步 | 折叠地图面板 |
| 音乐收藏 | 悬挂的小物件、节奏性摆动 | 紫蓝、暖金 | 低音氛围、轻旋律 | 唱片形面板 |

门牌可展示示例人物自愿公开的地区、年龄段、兴趣等标签。标签用来帮助探索，不直接决定观点或房间风格；第一版不使用真实玩家资料。

## 资源清单与制作顺序

| 优先级 | 资源 | 第一版要求 |
|---|---|---|
| P0 | 刺猬角色 | 正背侧面轮廓、待机、走路；配色和一两件可切换配饰 |
| P0 | 森林地面与路径 | 一个连续可行走区域，苔藓与树根轮廓可读 |
| P0 | 树洞／茧房入口 | 共用入口模型，开关状态与茧丝展开动画 |
| P0 | 针毡蘑菇 | 单只、成簇、高矮变化，用于路标与空间层次 |
| P0 | 一间精致室内 | 完整展示布置、光、声音和信息面板 |
| P0 | 两间简化室内 | 至少通过颜色、主要道具与声音区分 |
| P0 | 界面与示例数据页 | 门牌、敲门、许可、提示、面板、返回 |
| P1 | 更多装饰、跑跳、情绪安抚 | 主路径稳定后再增加 |

参考图的针毡细丝不逐根制作：近景用少量毛束塑造轮廓，中远景以材质纹理和柔和光照传达触感。若制作时间紧，保留一间精致室内，另外两间使用同一空间模板换主题。

## 第一版交互基线

- 目标设备暂按桌面浏览器和键鼠：`WASD`／方向键移动，鼠标调整视角，`E` 或屏幕按钮交互，`Esc` 返回。
- 视角为略俯视的第三人称，镜头平滑跟随刺猬；选中树洞切近景；打开面板前切正面近景。
- 敲门许可是预设状态，界面明确告知结果；关门时不能进入。真实授权留给第二版。
- 网页数据界面打开前暂停角色移动，返回后恢复原房间位置与镜头。

## 阶段 0 验收条件

1. 产品主路径与第一版边界清楚，没有把真实玩家互访纳入首版。
2. 世界、角色、蘑菇和三间茧房的视觉方向能从参考板上判断。
3. 资源清单足以启动灰盒阶段，且精致室内与简化室内的优先级明确。
4. 数据页的入口、镜头切换与链接待接入状态明确。
5. 用户已确认其余范围；示例茧房内容主题为占位，标签待后续提供。可以开始阶段 1。

阶段 1 的产物将是真正可操作的灰盒 HTML：从自己的树洞移动到别人的树洞，敲门、进入、返回；暂不以正式美术作为验收条件。
