# 《破茧》阶段 4 体验优化验收

状态：**待用户验收**。打开 [`../reviews/stage-4.html`](../reviews/stage-4.html) 查看本阶段可玩版本。阶段 3 的刺猬、三间房主题和声音方案保留。

## 按本轮反馈调整

- 移除了左右两侧常驻的大说明面板。任务清单变为**左侧窄面板**，可在右上角设置中显示或隐藏；声音开关也移入设置。房间位置缩成顶部小标签。
- 键盘和鼠标操作说明以半透明、模糊底板放在**左下角**。底部靠近目标时的交互提示保留原有位置和样式。
- 数据面板连同贴合的**圆角矩形茧丝包裹**移到茧房左侧，正前方出口完整露出，中央通道可直接走到出口。用户提供的局部布局参考保存在 [`../public/assets/references/data-panel-anonymized-layout.png`](../public/assets/references/data-panel-anonymized-layout.png)。
- 3D 面板和[本地演示数据页](../reviews/demo-data-stage4.html)只呈现“**用户画像、浏览信息、内容标签**”三个区域。内容为脱敏的结构占位：没有真实年龄、性格、喜好、网址、浏览时间、浏览轨迹或推荐路径。
- 靠近面板按 **E** 或点击底部互动按钮时，直接打开本房间配置的 `dataUrl`，正常流程没有第二次点击。游戏仍留在原标签页和原房间；切回后按 **Esc** 继续探索。

## 原定的阶段 4 检查

| 项目 | 本版处理 |
|---|---|
| 加载与资源 | 本地 Three.js 和内容配置；有启动遮罩，首次渲染后消失；WebGL 或场景创建失败时显示可读错误。 |
| 帧率 | 设置里显示实时 FPS；持续低于 28 FPS 且设备像素比高于 1 时自动降到 1 倍渲染精度。 |
| 碰撞 | 除茧房外壳外，增加树干和室内主要家具的简化阻挡，主通道仍可走通。 |
| 音频 | 保留用户手动开启的环境音；不支持或启动失败时给出提示，不阻断探索。 |
| 链接与失败恢复 | 不安全／未配置的地址不打开；浏览器拦截新标签时显示重试链接，关闭提示后仍在原房间。 |
| 连续主路线 | 从自己的茧房到三间主题房、数据页、返回森林和重置均纳入本地交互检查。 |

正式链接仍在 [`../public/data/cocoons-stage4.js`](../public/data/cocoons-stage4.js) 中逐房配置；目前指向项目内的脱敏演示页。正式人物与内容标签仍为空，等待你提供。对外站点的数据页采用新标签打开，因为对方站点可能不允许嵌入。

## 建议验收顺序

1. 打开阶段 4 HTML，确认画面不再被左右两个大面板挡住。右上角打开设置，切换任务面板与声音；查看左下角虚化操作说明和底部接近目标时的提示。
2. 进入一间茧房，确认左侧面板与正前方出口没有重叠，沿中央通道能走到出口；靠近左侧面板，确认圆角矩形茧丝贴合面板，三个信息区符合脱敏要求。
3. 按 **E** 打开面板，确认**直接**出现数据页新标签，没有中间确认卡片。切回游戏，按 **Esc** 后仍可原地行走。
4. 走访其余两间房，确认布置、色光、声音和探索记录仍可用；在设置中切换苔坡树桩开关门并测试。
5. 如浏览器拦截弹窗，确认有重试链接；设置内可查看帧率。连续走通两遍主路线，观察加载、画面和音效。
