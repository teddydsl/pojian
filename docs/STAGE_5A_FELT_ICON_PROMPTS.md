# 《破茧》新增功能图标：针毡风格生图提示词

## 范围与数量

根据“地图、天气、数据信息（个人数据／浏览过列表／好友列表）、任务成就（找人新手任务／完成反馈／奖励）、系统消息”整理。**当前只显示一种天气时，先需 11 枚；为天气切换补齐 5 种状态后，共 15 枚独立图标。**

| 模块 | 图标 | 数量 |
| --- | --- | ---: |
| 地图 | 地图入口 | 1 |
| 天气 | 晴、多云、雨、雾、风；当前状态的图标直接充当天气入口 | 5 |
| 数据信息 | 数据总入口、个人数据、浏览过列表、好友列表 | 4 |
| 任务成就 | 任务入口、找人任务、任务完成、初次探索徽章 | 4 |
| 系统消息 | 消息入口 | 1 |
| **合计** | | **15** |

这 15 枚是本轮功能范围，不包含地图上的各类地点标记、缩放按钮、设置按钮和空态插画。系统消息中的“完成任务”“获得徽章”可复用任务图标。天气若只显示固定状态，先生成当前状态那一枚即可（森林风格稿当前适合用“雾”）；其余四枚用于天气切换。夜晚属于昼夜状态，不作为天气图标计算。

**全套通用负面提示词**：文字、字母、数字、水印、品牌标志、九宫格、多个图标、按钮底板、背景场景、人物全身、复杂小细节、荧光色、塑料、金属、玻璃、扁平矢量、纯黑线稿、真实照片、强透视、硬投影、模糊边缘。参考图中的水印不要复制。

## 简短验收

生成后统一裁成同尺寸透明 PNG，并在实际界面中同时看 48px 和 32px：地图的路径、五种天气的形状、个人与好友的数量差异、完成对勾、徽章和消息铃都应一眼可读。若 32px 下纤维细节盖过主体，应让模型减少绒毛与缝线，保留大轮廓。所有图标须使用同一画布占比和同一侧光方向。
